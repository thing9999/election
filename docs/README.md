## 전체 흐름 한 장

```mermaid
flowchart TB
    subgraph PREP["준비 — DRAFT"]
        A1["선거 생성<br/>개표키 1회 표시"] --> A2["후보 등록"]
        A2 --> A3["명부 업로드<br/>회원번호·휴대폰·생년월일 해시"]
    end

    subgraph OPEN["투표 — OPEN"]
        B1["유권자 인증<br/>휴대폰 + 생년월일 + SMS 코드"] --> B2["브라우저에서 봉인<br/>133바이트"]
        B2 --> B3["1인1표 확정 + 표 저장<br/>같은 트랜잭션"]
    end

    subgraph CLOSE["마감 — CLOSED"]
        C1["무결성 점검"]
    end

    subgraph TALLY["개표 — TALLIED"]
        D1["선관위 2인 승인"] --> D2["개표키 주입<br/>서버에 저장 안 함"]
        D2 --> D3["봉인 개봉 후 집계<br/>개별 표는 저장하지 않음"]
    end

    subgraph PUB["공개 검증"]
        E1["누구나 사슬 대조<br/>로그인 불필요"]
    end

    PREP --> OPEN --> CLOSE --> TALLY --> PUB

    A3 -.->|"체크포인트 ROSTER_SEALED"| CP
    C1 -.->|"체크포인트 FINAL"| CP
    D3 -.->|"체크포인트 RESULTS"| CP
    CP["무결성 사슬<br/>+ 외부 고정"] --> E1
```

되돌아가는 전이는 API에 존재하지 않습니다. 개표를 되돌릴 수 있으면 결과를 신뢰할 수 없습니다.
